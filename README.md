# Boblox
Welcome to Boblox! A revival of Roblox, that is a 2008 full recreation that recreates almost everything with very similar physics and more

## 🎮 Getting Started

- **Main Site**: [Boblox Physics Engine](https://3000-in2r88m7x57f05ck8mpqf-5185f4aa.sandbox.novita.ai/)
- **Studio**: [Boblox Studio](studio.html) - Create games with our visual editor
- **Games**: [Community Games](games.html) - Play games made by the community

## 🎨 Features

### Physics Engine
- Realistic physics simulation with gravity, collisions, and materials
- Support for various shapes (parts, balls, wedges, cylinders)
- Material properties (plastic, wood, metal, etc.)
- Real-time physics calculations

### Studio Editor
- Visual game development environment
- Drag-and-drop object placement
- Property editor for fine-tuning
- Real-time preview and testing
- Scene embedding and sharing

### Web Interface
- Browser-based physics playground
- Chat system for community interaction
- Shape creation and material selection
- Scene saving and loading

## 🚀 Quick Start

1. Open [Boblox Studio](studio.html) to start creating
2. Use the toolbox to add objects to your scene
3. Adjust properties in the Properties panel
4. Click "Play" to test your game
5. Share your creations on the [Games](games.html) page

## 📁 Project Structure

- `index.html` - Main physics playground
- `studio.html` - Visual game editor
- `games.html` - Community games showcase
- `physics.cpp` - Core physics engine
- `renderer.cpp` - 3D rendering system
- `shape_builder.cpp` - Interactive shape creation
- `physics_wasm.cpp` - WebAssembly physics module
