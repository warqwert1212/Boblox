🔧 Using the Asset Loader

Basic Setup

// Initialize the asset loader const assetLoader = new BobloxAssetLoader(); assetLoader.initializeDefaultAssets(); // Get default assets const player = assetLoader.getAsset('default_player'); const spawn = assetLoader.getAsset('default_spawn'); const brick = assetLoader.getAsset('default_brick');

Loading Custom Assets

// Load custom asset from file (JSON/Boblox format) fetch('my-asset.boblox') .then(response => response.json()) .then(assetData => { const asset = assetLoader.loadBobloxAsset(assetData, 'my-custom-asset'); console.log('Asset loaded:', asset); });

Converting to Physics Parts

// Convert asset to physics engine format const asset = assetLoader.getAsset('default_player'); const physicsParts = assetLoader.convertToPhysicsParts(asset); // physicsParts is an array of part objects with: // - position, scale, rotation // - geometry information // - material properties (mass, friction, elasticity)

📝 Asset File Format

Boblox Format (.boblox)

Standard JSON-based format for Boblox assets with physics integration:

{ "name": "My Asset", "type": "part", "version": "1.0", "objects": [ { "name": "Object1", "position": { "x": 0, "y": 0, "z": 0 }, "scale": { "x": 1, "y": 1, "z": 1 }, "rotation": { "x": 0, "y": 0, "z": 0 }, "geometry": "BoxGeometry", "material": { "name": "plastic", "color": "#ff6b6b", "metalness": 0.3, "roughness": 0.7 } } ] }

Asset Types

  • part: Single physics object (brick, platform, etc.)
  • model: Multi-part assembled model (character, vehicle)
  • scene: Complete environment with multiple assets

🎯 Creating Custom Assets

Step 1: Open Asset Editor

Click the "Asset Editor" button and start creating your 3D model.

Step 2: Design Your Model

  • Drag objects from the Asset Library
  • Use tools to move, rotate, and scale
  • Apply materials and colors
  • Adjust physics properties

Step 3: Export Your Asset

Click "Export Asset" and choose:

  • Boblox Format: For engine integration (recommended)
  • JSON: For custom processing
  • GLB: For 3D viewers

Step 4: Use in Your Game

// Load your custom asset assetLoader.loadBobloxAsset(customAssetData, 'my-asset'); const assetParts = assetLoader.convertToPhysicsParts( assetLoader.getAsset('my-asset') ); // Use with physics engine assetParts.forEach(part => { // Add to your physics simulation physicsEngine.addPart(part); });

🎮 Default Assets Reference

Character (Player)

Components: Torso, Head, Arms, Legs
Material: Plastic (Green)
Use: Player-controlled character
Size: ~0.5 units tall

Spawn Point

Components: Platform (green, glowing)
Material: Plastic (Green with emissive)
Use: Player spawn location
Properties: Anchored (static, doesn't move)

Brick

Components: Single brick mesh
Material: Brick (Red)
Use: Building blocks, obstacles
Size: 2×1×1 units (customizable)

💡 Advanced Features

Combining Assets

// Merge multiple assets into one const combinedAsset = assetLoader.combineAssets([ 'default_player', 'default_brick' ]); // Result is a scene with all objects

Transforming Assets

// Move, rotate, or scale an entire asset assetLoader.transformAsset( 'my-asset', { x: 5, y: 0, z: 0 }, // position offset { x: 0, y: 0, z: 0 }, // rotation offset { x: 1, y: 1, z: 1 } // scale multiplier );

Calculating Physics Properties

// Automatic mass calculation based on material const mass = assetLoader.calculateMass({ scale: { x: 1, y: 1, z: 1 }, material: { name: 'metal' } }); // Metal with 1×1×1 scale = mass ~2.7
